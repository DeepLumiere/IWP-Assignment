# IWP Assignment - Team Portfolio Website

A modern, interactive team portfolio website built as part of an Internet and Web Programming (IWP) assignment. This project showcases a dynamic team presentation with individual member profiles and interactive features.

## 🌟 Features

- **Interactive Team Dashboard**: Dynamic card-based layout showcasing team members
- **Individual Bio Pages**: Dedicated pages for each team member with detailed information
- **Dynamic Employee Management**: Add new team members through an interactive form
- **Responsive Design**: Mobile-friendly interface with modern CSS styling
- **3D Text Effects**: Interactive mouseover effects on portfolio elements
- **Modern Build System**: Powered by Vite for fast development and optimized production builds

## 🚀 Getting Started

### Prerequisites

- Node.js (v14 or higher)
- npm (Node Package Manager)

### Installation

1. Clone the repository:

```bash
git clone https://github.com/DeepLumiere/IWP-Assignment.git
cd IWP-Assignment
```

2. Install dependencies:

```bash
npm install
```

3. Start the development server:

```bash
npm run dev
```

4. Open your browser and navigate to the localhost URL shown in the terminal (typically `http://localhost:5173`)

### Building for Production

To build the project for production:

```bash
npm run build
```

To preview the production build:

```bash
npm run preview
```

## 💻 Development

### Code Formatting

This project uses Prettier for code formatting. Configuration is available in `.prettierrc`.

To format code:

```bash
npx prettier --write .
```

### Adding New Team Members

You can add new team members dynamically through the web interface:

1. Navigate to the main page (`index.html`)
2. Scroll to the "Add New Employee" form
3. Fill in the employee name, project, and link
4. Click "Add Card" to add the new member

### Customizing Styles

- Main styling: `src/styles.css`
- Blue theme: `src/stylesblue.css`
- Individual pages may have inline styles for specific effects
